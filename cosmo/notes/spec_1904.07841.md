## 1. Bibliographic line and claims

D. Daverio, Y. Dirian, E. Mitsou, "General Relativistic Cosmological N-body Simulations I: time
integration" (L26-30). The authors are at DAMTP Cambridge and ICS Zürich (L33-34). The source
gives no journal; it uses `jcappub` (L13). From memory, and to be checked: JCAP 10 (2019) 065.
The code is built on LATfield2 (L99).

The paper's own claims (abstract L45, introduction L93), in three sentences:
1. A damped-CCZ4 scheme, fourth-order finite differences, RK4 for the fields and a subcycled
   drift-kick-drift for the particles together give a stable N-body numerical-relativity
   evolution. It passes an FLRW robustness (white-noise) test and follows a single scalar
   linear mode around FLRW.
2. It evolves typical ΛCDM-like (pure-matter) initial conditions from z = 1000 to z = 0, with
   comoving resolution down to about 1 Mpc/h. Throughout, L1 of the relative Hamiltonian
   constraint stays ~1e-6, L1 of the relative momentum constraint ~1e-2, and the relative
   energy-momentum conservation violation ~1e-2, all the way into strong inhomogeneity.
3. The linear power spectrum is followed to ~1e-2 relative precision. Convergence has the
   expected order at early times but is lost after z ~ 10 in the small box. The authors blame
   fixed mesh and phase-space resolution and expect adaptive methods to fix it.

## 2. Formulation

### 2.1 Units and conventions
- Units: 8πG = c = Mpc/h = 1 (L97). The cosmological constant is zero in all tests (L98).
- Line element: ds² = −α²dt² + γ_ij(dx^i + β^i dt)(dx^j + β^j dt) (L143).
- Conformal split: γ_ij := χ^{-1} γ̃_ij, K_ij := χ^{-1}(Ã_ij + (1/3) γ̃_ij K) (L147),
  with det γ̃ = 1 (constraint D, L134). So χ = (det γ)^{-1/3}, the usual moving-puncture χ.
- Sign of K: K < 0 for expansion. On FLRW, K = −3a^{-1}ℋ (L323) and ∂_t χ = (2/3) χ α K.
  This is the standard ADM sign, K_ij = −(1/2α) L_n γ_ij.
- Matter variables: E, P_i, S_ij are the energy, momentum and stress densities in the frame
  n = α^{-1}(∂_t − β^i ∂_i) (L149).
- All tilde indices are raised and lowered with γ̃_ij (L141).
- t is conformal time on FLRW (L159, L329); comoving coordinates; coordinate light speed = 1.
- H0 := 100 km/s/(Mpc/h) ≈ 3.336e-4 in these units (L343). [derived] Exactly
  100/299792.458 = 3.33564e-4.

### 2.2 Evolution system: damped CCZ4 (L109-131), verbatim

Evolved: Θ, Γ̂^i, χ, K, γ̃_ij, Ã_ij (plus α; β^i is fixed to zero). D_t := ∂_t − β^i ∂_i (L124).

$$D_t\Theta = \alpha\left[-K\Theta - \kappa_1(2+\kappa_2)\Theta - H\right] - \chi\tilde Z^i\partial_i\alpha \qquad (L111)$$

$$D_t\hat\Gamma^i = 2\alpha\left[\tilde\Gamma^i_{jk}\tilde A^{jk} - \tfrac32\tilde A^{ij}\chi^{-1}\partial_j\chi + \tilde\gamma^{ij}\left(\partial_j\Theta - \tfrac23\partial_jK - P_j\right) - \left(\tfrac23K+\kappa_1\right)\tilde Z^i\right] - 2\Theta\tilde\gamma^{ij}\partial_j\alpha - 2\tilde A^{ij}\partial_j\alpha + \tilde\gamma^{jk}\partial_j\partial_k\beta^i + \tfrac13\tilde\gamma^{ij}\partial_j\partial_k\beta^k - \hat\Gamma^j\partial_j\beta^i + \tfrac23\hat\Gamma^i\partial_j\beta^j \qquad (L112\text{-}113)$$

$$D_t\chi = \tfrac23\chi\left[\alpha K - \partial_i\beta^i\right] \qquad (L114)$$

$$D_tK = \alpha\left[K^2 - 2K\Theta - 3\kappa_1(1+\kappa_2)\Theta + 2\tilde Z^i\partial_i\chi - \tfrac32E\right] + \chi\tilde\Gamma^i\partial_i\alpha + \tilde\gamma^{ij}\left[-\chi\partial_i\partial_j\alpha + \tfrac12\partial_i\chi\partial_j\alpha + \alpha\left(\hat R_{ij} + \tfrac12\chi S_{ij}\right)\right] \qquad (L115\text{-}116)$$

$$D_t\tilde\gamma_{ij} = -2\alpha\tilde A_{ij} + \tilde\gamma_{ik}\partial_j\beta^k + \tilde\gamma_{jk}\partial_i\beta^k - \tfrac23\tilde\gamma_{ij}\partial_k\beta^k \qquad (L117)$$

$$D_t\tilde A_{ij} = \alpha\left[-2\tilde\gamma^{kl}\tilde A_{ik}\tilde A_{jl} + (K-2\Theta)\tilde A_{ij}\right] + \left[\chi\left(-\partial_i\partial_j\alpha + \tilde\Gamma^k_{ij}\partial_k\alpha\right) - \partial_{(i}\chi\,\partial_{j)}\alpha + 2\alpha\tilde Z^k\tilde\gamma_{k(i}\partial_{j)}\chi + \alpha\left(\hat R_{ij} - \chi S_{ij}\right)\right]^{\rm TF} + \tilde A_{ik}\partial_j\beta^k + \tilde A_{jk}\partial_i\beta^k - \tfrac23\tilde A_{ij}\partial_k\beta^k \qquad (L118\text{-}120)$$

Definitions (L124-130):
- Γ̃^i := −∂_j γ̃^{ij}
- Z̃^i := (1/2)[Γ̂^i − Γ̃^i]
- Γ̃_kij := (1/2)(∂_i γ̃_jk + ∂_j γ̃_ik − ∂_k γ̃_ij)
- Γ̃^k_ij := γ̃^{kl} Γ̃_lij

$$\hat R_{ij} := \chi\left[-\tfrac12\tilde\gamma^{kl}\partial_k\partial_l\tilde\gamma_{ij} + \tilde\gamma_{k(i}\partial_{j)}\hat\Gamma^k + \tilde\Gamma_{(ij)k}\hat\Gamma^k + \tilde\gamma^{kl}\left(\tilde\Gamma^m_{ki}\tilde\Gamma_{mlj} + 2\tilde\Gamma^m_{k(i}\tilde\Gamma_{j)ml}\right)\right] + \tfrac12\left[\partial_i\partial_j\chi - \tfrac12\chi^{-1}\partial_i\chi\partial_j\chi + \tilde\gamma_{ij}\tilde\gamma^{kl}\left(\partial_k\partial_l\chi - \tfrac32\chi^{-1}\partial_k\chi\partial_l\chi\right) - \tilde\Gamma^k_{ij}\partial_k\chi - \tilde\gamma_{ij}\hat\Gamma^k\partial_k\chi\right] \qquad (L129\text{-}130)$$

[derived] R̂_ij is χ times the physical Ricci tensor, with Γ̂ in place of Γ̃. Hence
γ̃^{ij} R̂_ij = R, the physical scalar curvature.

Other schemes (L149): substituting K → K + 2Θ gives "Z4cc"; then setting Θ = 0 gives BSSNOK.
The footnote at L149 says that dropping some pure-constraint terms of Z4cc gives Z4c
(Bernuzzi-Hilditch). The derivation is in Daverio:2018tjf.

### 2.3 Constraints (L133-139), verbatim
- D := det γ̃ − 1 = 0
- D' := γ̃^{ij} Ã_ij = 0
- Θ = 0
- Z̃^i = 0

$$H := E - \tfrac13K^2 + \tfrac12\tilde A_{ij}\tilde A^{ij} - \tfrac12\tilde\gamma^{ij}\hat R_{ij} - \tilde Z^i\partial_i\chi = 0 \qquad (L138)$$

$$M_i := P_i - \tilde\gamma^{jk}\left[\partial_j\tilde A_{ki} - \tilde A_{li}\tilde\Gamma^l_{kj} - \tilde A_{kl}\tilde\Gamma^l_{ij} - \tfrac32\tilde A_{ij}\chi^{-1}\partial_k\chi\right] + \tfrac23\partial_iK = 0 \qquad (L139)$$

[derived] Normalisation: H = E − (1/2)(R + (2/3)K² − A_ijA^ij) + Z terms. The usual form
R + (2/3)K² − A_ijA^ij − 16πGρ therefore equals −2H. M_i has the opposite sign to the usual
D_j A^j_i − (2/3)∂_i K − 8πG S_i and the same magnitude.

D' is imposed by hand at every RK4 substep: Ã_ij → Ã_ij − (1/3) γ̃_ij γ̃^{kl} Ã_kl (L286-289).
**D (det γ̃ = 1) is not said to be imposed**; it is only monitored (L313).

### 2.4 Gauge (L151-163)
- Lapse, Bona-Masso type (L153): **∂_t α − β^i ∂_i α = −(1/3) α² [K − 2Θ]**. This is
  f(α) = 1/3 applied to K − 2Θ, the Z4c K̂.
- Shift: **β^i = 0** (L157) at all times.
- If Θ = 0 the lapse integrates to α = Q χ^{-1/2} (L161), with Q(x) a free spatial function.
  Q = 1 on FLRW (L329). In the linear-perturbation setup Q = 1 + ψ (L598).
- This gauge makes t conformal time on FLRW (L159).

### 2.5 Constraint damping (L165-177)
- κ1 and κ2 multiply pure-constraint terms and may depend on space and time (L165).
- Linearised around FLRW (L167):
  Θ̇ = −α[K + κ1(2 + κ2)]Θ + …,  Ż̃^i = −α((2/3)K + κ1) Z̃^i + ….
- Minkowski stability bounds are κ1 ≥ 0, κ2 ≥ −1 (L171). Because K < 0 in cosmology,
  κ1 = 0 is unstable: Θ and Z̃ grow exponentially, worst at early times (L173).
- **Used in every run (L175, L177): κ1 = −(2/3) K, κ2 = −1/2.** This is "effectively
  undamped": it cancels exactly the displayed linear terms. Here K is the evolved K, a
  field; the text does not say whether the local or the background value is used. [derived]
  κ1 = 21.1 at z = 1000 and 2H0 = 6.7e-4 at z = 0.

### 2.6 Particles (L179-188; derivation App. A, L556-590)
There are N particles of equal mass m, with positions x_a^i(t) and covariant canonical momenta
p_i^a(t). The time parameter is the coordinate t, not proper time (L560-564).

$$\dot x^i_a = -\beta^i + \alpha\chi E_a^{-1}\tilde\gamma^{ij}p^a_j \qquad (L181)$$

$$\dot p^a_i = -E_a\partial_i\alpha + p^a_j\partial_i\beta^j + \alpha E_a^{-1}\left[\chi\tilde\gamma^{jl}\tilde\Gamma^k_{il}p^a_jp^a_k - \tfrac12\left(E_a^2-m^2\right)\chi^{-1}\partial_i\chi\right] \qquad (L182)$$

$$E_a := \sqrt{m^2 + \chi\tilde\gamma^{ij}p^a_ip^a_j} \qquad (L186)$$

All fields are evaluated at x_a. In ADM form (L588):
ẋ^i = −β^i + α γ^{ij} p_j / E_a and ṗ_i = −E_a ∂_iα + p_j ∂_iβ^j + α γ^{jl} Γ^k_il p_j p_k / E_a.
I checked that L182 is the conformal rewrite of this.

Continuum sources (L582-584): E = Σ E_a δ³(x − x_a)/√γ, P_i = Σ p_i^a δ³/√γ,
S_ij = Σ p_i^a p_j^a / E_a · δ³/√γ.

### 2.7 Space discretisation (L198-213)
- First derivatives use the centred 5-point stencil, printed as (L200):
  ∂_i f → [−2f(x+2Δ_i) + 8f(x+Δ_i) − 8f(x−Δ_i) + 2f(x−2Δ_i)] / (12Δx).
  **Erratum.** A Taylor expansion of this gives (2/3)f' − (2/9)Δx²f''' + …, which is not
  consistent. The intended stencil is the standard fourth-order one,
  [−f(x+2Δ_i) + 8f(x+Δ_i) − 8f(x−Δ_i) + f(x−2Δ_i)] / (12Δx).
- Advection term β^i ∂_i in D_t uses one-sided 5-point stencils (L208). This is irrelevant
  because β = 0.
- Diagonal second derivatives use (−1, 16, −30, 16, −1)/(12Δx²) (L212). Mixed ∂_i∂_j (i ≠ j)
  are presumably the 5-point first-derivative stencil applied twice (not stated).
- Kreiss-Oliger dissipation, 6th order (L290-295), added to the RHS of every gravitational
  field (which fields exactly is not listed):
  Δ_KO = (σ / (64Δx)) Σ_i [f(x+3Δ_i) − 6f(x+2Δ_i) + 15f(x+Δ_i) − 20f(x) + 15f(x−Δ_i)
  − 6f(x−2Δ_i) + f(x−3Δ_i)].
  **σ = 0.05** (L300). Stability bound 0 ≤ σ ≤ 2/C (L298). The sign is dissipative as
  printed: on the Nyquist mode it gives −σf/Δx.

### 2.8 Particle-mesh coupling (L214-228)
Deposit, verbatim (L216-218):
- E(x) := χ^{3/2}(x) Σ_a E_a W^{(3)}(x − x_a)
- P_i(x) := χ^{3/2}(x) Σ_a p_i^a W^{(3)}(x − x_a)
- S_ij(x) := χ^{3/2}(x) Σ_a p_i^a p_j^a / E_a · W^{(3)}(x − x_a)

with W^{(3)}(x) := Π_i W(x^i) (L222). The 1D kernel as printed (L226):

    W(x) = 3/4 + (x/Δx)^2          if 0 <= |x| <= Δx/2
           (1/2)(3/2 - x/Δx)^2     if Δx/2 <= x <= 3Δx/2
           0                       otherwise

**Erratum.** This is meant to be the standard triangular-shaped-cloud (TSC) quadratic
B-spline: 3/4 − (x/Δx)² in the inner region and (1/2)(3/2 − |x|/Δx)² in the outer region.
The printed "+" and the missing |x| are typos.

**Normalisation.** The mass formula m = 3H0²Δx³/N_ppc (L353) reproduces
E_FLRW = 3H0² a^{-3} only if each 1D factor carries 1/Δx. So use W(x) = TSC(x/Δx)/Δx for
deposition. [derived]

- Interpolation of fields to particles uses "the inverse kernel" (L228): the same TSC weights,
  f(x_a) = Σ_g f(x_g) TSC((x_g − x_a)/Δx) with dimensionless weights summing to 1.
- Interpolated set G = {α, ∂_iα, β^i, ∂_iβ^i, χ, ∂_iχ, γ̃_ij, Γ̃^k_ij} (L241). The derivatives
  and Christoffels are therefore computed on the mesh by finite differences and then
  interpolated. How γ̃^{ij} is obtained at the particle is not stated.
- The particle sums are updated only at particle steps (every N_sΔt). The factor χ^{3/2} is
  re-applied "at every step" (L300). Whether that means every RK4 step or every RK4 substep
  is not stated.

### 2.9 Time integration and the main loop (L237-300, Fig. 3)
- Courant factor C := Δt/Δx < 1, constant (L239). C = 0.1 in tests A and B, 0.05 in test C.
- Fields: classical RK4 with step Δt. Particles: "drift-kick-drift" advanced every N_s field
  steps. **N_s = 8** (L241); constraint violation is "significantly reduced" when N_s ≈ 10.
- Positions advance by steps of N_sΔt and momenta by steps of 2N_sΔt (L241).

The loop, verbatim (L245-276). Write T := N_sΔt. At the start of a cycle the code holds the
fields G(t), the positions x(t) and the momenta p(t − T).

1. Drift: x(t+T) = x(t) + ẋ[p(t−T), G(t, x(t))] · T.
2. Update the matter fields E, P_i, S_ij (deposit).
3. Advance the fields by Δt with RK4, N_s times: G(t) → G(t+T).
4. Kick: p(t+T) = p(t−T) + ṗ[p(t−T), G(t+T, x(t+T))] · 2T.
5. Update the matter fields.
6. Advance the fields by Δt with RK4, N_s times: G(t+T) → G(t+2T).
7. Drift: x(t+2T) = x(t+T) + ẋ[p(t+T), G(t+2T, x(t+T))] · T.
   Note that this uses the fields at t+2T but the old position x(t+T).
8. t → t + 2T.

Fig. 3 (`main_loop.pdf`) draws the same cycle in boxes: Particle Drift N_sΔt → PM projections
→ Gravity RK4 Δt (N_s times) → Particle Kick 2N_sΔt → PM projections → Gravity RK4 Δt
(N_s times) → Particle Drift N_sΔt → back to the start.

[derived] Both deposits in a cycle use the positions x(t+T). The fields over the whole
interval [t, t+2T] therefore see the particle positions at its midpoint. The momenta used are
p(t−T) on [t, t+T] and p(t+T) on [t+T, t+2T].

The kick evaluates ṗ with the old momentum p(t−T), so it is explicit in p. The authors
contrast their scheme with a staggered leapfrog in which steps 7 and 1 would merge: in theirs,
x(t+2T) depends on the fields at both x(t) and x(t+T) (L300).

[inferred from figure abscissae] Diagnostics are written once per cycle, every 2T = 16Δt. The
first plotted points sit at t = 2T. Runs stop at the first cycle with t ≥ t_f: final t is
5811.2 for Δx = 8 at C = 0.1, and 5808 or 5806.4 elsewhere.

### 3.2 Test A: FLRW robustness (white noise), verbatim (L363-376)
Fields:
- α(0,x) = a(0)[1 + ε]
- χ(0,x) = a^{-2}(0)[1 + ε]
- Θ(0,x) = ε
- K(0,x) = −3(a^{-1}ℋ)(0)[1 + ε]
- Γ̂^i(0,x) = ε^i
- γ̃_ij(0,x) = δ_ij + ε_ij
- Ã_ij(0,x) = ε_ij

Particles: δx_a^i(0) = ε_a^i (displacement from the lattice) and p_i^a(0) = m ε_i^a (L374).

Every ε is drawn independently from a uniform distribution, for each component and for each
grid point or particle (L376). Amplitudes:
- fields: **1e-7 · N_g^{-2}**
- particles: **1e-7 · N_g^{-3}**

The footnote at L376 explains the scalings: second derivatives of noise grow like N_g². The
particle scaling keeps the density noise ∝ N_g^{-2}; with N_g^{-2} for particles, E did not
converge.

Grids: L = 64, Δx ∈ {8, 4, 2}, so N_g ∈ {8, 16, 32}. C = 0.1, N_ppc = 1 (L376).

[inferred] L∞(δχ) at t = 0 equals 1e-7/N_g² exactly (1.562e-9, 3.906e-10, 9.765e-11 (fig)).
So "amplitude" means max|ε| = A. The figure cannot distinguish U(−A, A) from U(0, A).

[derived] For N_ppc = 1: N = 512, 4096, 32768 particles; m = 1.709e-4, 2.136e-5, 2.670e-6.

### 3.3 Test B: scalar linear mode (L411-415, App. B L596-677)
Target: δ⋆(0, x, y, z) = A sin(2πx/L) (L413), with A = 1e-7, L = 128, Δx ∈ {4, 2, 1},
C = 0.1 and N_ppc = 27 (L415). The text says the mode starts outside ℋ^{-1}(0) ≈ 95 and ends
inside, and that δ⋆ reaches ~1e-4 at z = 0 (L415).

Fields follow App. B. The perturbation ansatz is (L598-605):
- Q = 1 + ψ
- χ = a^{-2}(1 + 2φ)
- α = a(1 + ψ − φ)
- K = −3a^{-1}ℋ(1 + h)
- γ̃_ij = δ_ij + 2(∂_i∂_j − (1/3)δ_ij∂²)φ̃
- Ã_ij = −a^{-1}ℋ(∂_i∂_j − (1/3)δ_ij∂²)h̃
- E = 3a^{-2}ℋ²(1 + δ)
- P_i = 3a^{-1}ℋ² ∂_i v, where v is a comoving velocity potential.

Gauge-invariant variables (L629): δ⋆ := δ − 3ℋv and v⋆ := v + φ̃̇.
Linear constraints (L633): k²Φ = −(3/2)ℋ²δ⋆ and Φ̇ + ℋΨ = −(3/2)ℋ²v⋆.

The residual gauge is fixed by ψ(x) = 2φ(0,x) (L637) and φ̃(0) = h̃(0) = 0 (L657). The
Zel'dovich condition Φ̇(0) = 0 then gives φ(0) + h(0) = 0 (L661). Then φ, φ̃, h and h̃ stay
constant: φ̃ = h̃ = 0 and h = −φ(0) (L665). The metric is conformal Newtonian (L669):
ds² = a²[−(1 + 2φ)dt² + (1 − 2φ)dx²].

The density and velocity evolve as (L673):
δ(t,x) = −2[1 − (1/3)∂²/ℋ²(t)] φ(0,x) and v(t,x) = −(2/(3ℋ(t))) φ(0,x).

[derived] The mesh fields at t = 0 that follow:
- φ0 from ∂²φ0 = (3/2)ℋ0² δ⋆, so φ0 = −(3/2)(ℋ0²/k²) A sin(kx) with k = 2π/L.
- χ = a0^{-2}(1 + 2φ0), α = a0(1 + φ0), K = −3a0^{-1}ℋ0(1 − φ0).
- γ̃ = δ, Ã = 0, Θ = 0, Γ̂ = 0, β = 0.
- E = 3a0^{-2}ℋ0²(1 + δ0) with δ0 = δ⋆ − 2φ0.
- P_i = −2a0^{-1}ℋ0 ∂_iφ0.

Numbers: |φ0| = 6.933e-9, |δ0| = 1.1387e-7, and δ amplitude at t_f = 1.0011e-4.

## 6. Gaps, errata, and code-specific items

### 6a. Left unstated but needed for a reproduction
1. **Particle initial data.** How x_a(0) and p_a(0) are made to reproduce E(0) and P_i(0)
   (withheld, L351). This includes:
   - the lattice offset relative to mesh points (vertex or cell centre);
   - the 3×3×3 sub-lattice for N_ppc = 27;
   - first or second order Zel'dovich;
   - whether the displacement field is TSC-interpolated to particles (Fig. 7 suggests yes);
   - how p(−N_sΔt), needed by the first drift, is initialised.
2. **Field initial data from the particles.** Analytic linear-theory fields, or constraints
   solved from the deposited E and P? Fig. 7 (sinc⁶ factor) and the footnote at L446
   (φ + h ~ 1e-3 φ) point to the latter, but the solver, its linearity and its order are not
   given.
3. **Power spectrum.** CLASS cosmological parameters (Ω_m, Ω_b, h, n_s, A_s or σ8), which
   transfer function and gauge, the random-field generator and seed, Gaussianity, and the
   cut-off shape (Fig. 15 suggests it is not a sharp spherical |k| cut). The simulations
   themselves are pure matter with Λ = 0 (L98, L349).
4. **κ1 = −(2/3)K.** Local evolved K or background K? Updated per substep?
5. **Robustness noise.** U(−A, A) or U(0, A)? Are the 6 components of ε_ij independent? Are
   D and D' violated by the noisy data (D' is projected out at the first substep)?
6. **Deposit and interpolation details.**
   - Which metric is used for E_a in the deposit.
   - Whether "every step" for the χ^{3/2} refresh means each RK4 substep.
   - Whether γ̃^{ij} at a particle comes from inverting the interpolated γ̃_ij or from
     interpolating γ̃^{ij}.
   - Mixed second-derivative stencil.
   - Which fields receive KO dissipation (α? Θ?).
7. **Terms in the relative constraints.** What counts as one "term" T_n in H_r, M_r, C^E_r and
   C^P_r: is γ̃^{ij}R̂_ij one term, or expanded per L129? In C^E, is Γ̃^i the computed −∂_jγ̃^{ij}
   or Γ̂^i? For cosmology E ≈ K²/3 dominates, so the H_r denominator is about √2·E either way.
8. **Output and norms.** Output cadence (once per loop cycle, [inferred]). Is δ for P(k) and
   δ_δ defined against the FLRW Ē(t) or the box mean? FFT normalisation of P_num.
9. **Boundary conditions.** Periodic is implied, never stated.
10. **Stopping rule.** First cycle with t ≥ t_f, [inferred].
11. **Slices.** Location, colour scale and quantity scaling of Figs. 1-2.

### 6b. Errata and inconsistencies found
- **Eq. (Pkevol), L677, is missing a square.** The data follow
  [(3 + k²/ℋ²(t)) / (3 + k²/ℋ²(0))]² P(0,k).
- **TSC kernel, L226:** "3/4 + (x/Δx)²" should be "3/4 − (x/Δx)²"; the second branch needs
  |x|; the kernel needs a 1/Δx per dimension for L353 to hold.
- **First-derivative stencil, L200:** the ±2Δx weights are printed as ∓2 instead of ∓1. As
  printed the stencil gives (2/3)f'. Use [−f(x+2) + 8f(x+1) − 8f(x−1) + f(x−2)]/(12Δx).
- **Test B sign:** the plotted φ has the opposite sign to the one implied by δ⋆ = +A sin
  (§3.3).
- **C^P_r, L531:** the numerator √(C^P_i C^P_i) uses δ^{ij} while the denominator uses γ^{ij}.
  Taken literally the ratio picks up a factor ~1/√χ = a. Use γ^{ij} in both.
- **Fig. 14 caption** says "Hamiltonian" for M.
- **L241:** "∂_iβ^i" in G means all ∂_iβ^j (irrelevant with β = 0).
- **L503:** "at most ~1e-6 / ~1e-2" is loose. The figures reach 5e-6 for H_r and 7e-2 for M_r
  at z ≈ 0 (C256 coarse).

### 6c. Specific to their code; equivalents in a Z4c / moving-puncture block-mesh code
1. **CCZ4 (Alic et al.) instead of Z4c.**
   - CCZ4 evolves K = tr K_ij; Z4c evolves K̂ = K − 2Θ and drops several non-principal
     Θ- and Z-terms. For example, Bernuzzi-Hilditch Θ̇ has no −αKΘ term, and Θ enters only
     through (2/3)(K̂ + 2Θ)² in H̃.
   - The Γ damping normalisation differs: CCZ4 has −2ακ1 Z̃^i = −ακ1(Γ̂ − Γ̃). The host code
     has −2ακ1(Γ̂ − Γ̃) (`z4c_calcrhs.cpp`), i.e. twice as large for the same κ1.
   - So the "effectively undamped" choice κ1 = −(2/3)K, κ2 = −1/2 (L175) is not transferable
     as is. Linearise the host's Θ, K̂ and Γ̂ equations about FLRW (α = a, χ = a^{-2},
     K̂ = −3a^{-1}ℋ) to find the K-proportional terms. Then choose κ1(x,t) to cancel them, or
     run κ1 = 0 and κ1 = c·|K̂| and compare.
   - The host has only constant `damp_kappa1` and `damp_kappa2`, so a field-dependent κ1
     needs a code change.
2. **Lapse: f = 1/3 harmonic-type slicing, not 1+log.** Host setting: `lapse_oplog = 0`,
   `lapse_harmonic = 1/3`, which gives ∂_tα = −(1/3)α²K̂. This is identical, since K̂ = K − 2Θ.
   Also `lapse_advect` is irrelevant and slow-start lapse must be off. With 1+log, t is not
   conformal time and C = Δt/Δx would not stay meaningful.
3. **Shift β ≡ 0.** Set `shift_ggamma = 0`, `shift_alpha2ggamma = 0`, `shift_hh = 0` and
   β(0) = 0.
4. **Stencil orders.** 4th-order centred FD with 6th-order KO (σ = 0.05, prefactor σ/(64Δx)).
   The host's FD and KO order follow NGHOST: `diss` × 2^{−2·NGHOST}. With NGHOST = 3 this
   matches σ/64 for a 6th-order operator. Check the 1/Δx factor and the sign convention in
   `Diss<NGHOST>`. With NGHOST = 4 the operators differ: 6th-order FD with 8th-order KO.
5. **Algebraic constraints.** Only tr Ã = 0 is enforced (each substep); det γ̃ = 1 is not. The
   host probably enforces both. This is a minor difference to note.
6. **Mesh.** Uniform periodic Cartesian mesh, no refinement. Use a single level with periodic
   boundaries; disable every moving-puncture safeguard: χ floor, excision, drift control,
   puncture tracking.
7. **Coupled stepping.** Subcycled drift-kick-drift with N_s = 8 and frozen particle sources
   (§2.9) is specific to them. The host's particle pusher and its coupling are different.
   Either implement the loop as specified, or keep the host's scheme, report N_s = 1
   equivalence, and test sensitivity: the paper says the constraint level depends on N_s.
8. **Particle-mesh scheme.** TSC for both deposit and interpolation; mesh derivatives
   interpolated (not differentiated at the particle). Make the host's kernel TSC.
9. **Units.** The host uses G = 1 with explicit 8π and 16π source factors. Map
   E_paper = 8π E_host, P_i,paper = 8π S_i,host, S_ij,paper = 8π S_ij,host, and so
   m_host = 3H0²Δx³ / (8π N_ppc). Keep the same length unit, Mpc/h.
   H_host = R + (2/3)K² − AA − 16πE_host = −2 H_paper. Check the host's M normalisation the
   same way before comparing absolute constraints.
10. **LATfield2.** No counterpart needed.
