## 1. Bibliographic lines and the paper's claim

- Part II: C. Barrera-Hinojosa and B. Li, "GRAMSES: a new route to general relativistic N-body
  simulations in cosmology. Part II. Initial conditions", arXiv:2001.07968 (II:20-30). JCAP
  format; the journal reference is not in the source.
- Part I: same authors, "... Part I. Methodology and code description", JCAP 2020 (2020) 007,
  arXiv:1905.08890 (II bbl lines 4-10).

What it shows, in its own terms (abstract II:32-33, conclusion II:434-438): GRAMSES uses a
constant-mean-curvature slicing with a minimal-distortion shift, in which the linear growth rate
is scale dependent, so the standard displacement-plus-growth-rate recipe for particle velocities
does not apply. The paper realises positions from the matter power spectrum at z_ini with the
Zel'dovich approximation and obtains velocities by finite-differencing displacements realised
with the same random seed from power spectra at z_ini ± Δz, implemented in a modified 2LPTic fed
by a modified CAMB. In a Newtonian setting this reproduces the default 2LPTic velocities to
sub-percent accuracy, the matter and velocity spectra of the GRAMSES-gauge ICs agree with linear
theory in that gauge, and corrections for radiation and for the σ8 normalisation at z_ini ± Δz
are needed.

Important: every Part II test is on initial-condition data at z_ini. Nothing is evolved, except
that GRAMSES is started once to solve for the initial shift and write its first snapshot
(II:412).

## 2. Formulation and gauge of the target code (GRAMSES, Part I)

Signature (-,+,+,+), c = 1 (II:55); Part I §2 also sets G = 1 (e.g. 16πρ in I-main:53), Part II
§4 and App. A write G explicitly.

### 2.1 Metric and decomposition

- ADM metric (I-main:49, II:62):
  $ds^2=-\alpha^2dt^2+\gamma_{ij}(\beta^i dt+dx^i)(\beta^j dt+dx^j)$.
- Constraints (I-main:53-54): $R+K^2-K_{ij}K^{ij}=16\pi\rho$,
  $D_j(K^{ij}-\gamma^{ij}K)=8\pi S^i$, with $\rho=n_\mu n_\nu T^{\mu\nu}$,
  $S_i=-\gamma_{i\mu}n_\nu T^{\mu\nu}$, $n_\mu=(-\alpha,0)$ (I-main:58-61); evolution equations
  I-main:63-64 (standard ADM; not solved in GRAMSES).
- Conformal split (I-main:78-82): $\gamma_{ij}=\psi^4\bar\gamma_{ij}$, $\psi^4=\gamma^{1/3}$,
  $A_{ij}=K_{ij}-\gamma_{ij}K/3$, $A^{ij}=\psi^{-10}\bar A^{ij}$; indices of barred quantities
  moved with $\bar\gamma_{ij}$.
- CTT split (I-main:94-98): $\bar A^{ij}=\bar A^{ij}_{TT}+\bar A^{ij}_L$,
  $\bar A^{ij}_L=(\bar LW)^{ij}\equiv\bar D^iW^j+\bar D^jW^i-\tfrac23\bar\gamma^{ij}\bar D_kW^k$.
- Fully constrained / conformally flat approximation, imposed at all t (I-main:153, II:93):
  $\bar\gamma_{ij}=\delta_{ij},\ \bar A^{ij}_{TT}=0$. No tensor modes, no evolution equation for
  gravity; metric is a functional of the particle data at each step (II:171).

### 2.2 Gauge

- Slicing: CMC, $K=-3H(t)$ (I-main:116, II:66), H = ȧ/a a prescribed fiducial Hubble rate fixed
  by reference Friedmann equations (I-main:124-125):
  $H^2=\tfrac{8\pi}{3}(\hat\rho_m+\rho_\Lambda)$,
  $H^2+\dot H=-4\pi(\hat\rho_m+\rho_\Lambda+3\hat P)$ (as printed).
  Lapse from the elliptic CMC condition (II:70, I-main:184):
  $\bar\nabla^2(\alpha\psi)=\alpha\left[2\pi\psi^{-1}(s_0+2s)+\tfrac78\psi^{-7}\bar A_{ij}\bar A^{ij}+\psi^5\left(\tfrac{5K^2}{12}+2\pi\rho_\Lambda\right)\right]-\psi^5\dot K$.
- Threading: minimal distortion (I-main:135, II:83) $D^i(\gamma^{1/3}\partial_t\bar\gamma_{ij})=0$;
  with conformal flatness it becomes (I-main:157, II:101)
  $(\bar\Delta_L\beta)^i=2\partial_j(\alpha\psi^{-6}\bar A^{ij}_L)$,
  $(\bar\Delta_L\beta)^i\equiv\bar D_j(\bar L\beta)^{ij}$. The shift has scalar and vector parts
  (II:103), unlike the Poisson gauge.
- Redshifts quoted are those of the reference FLRW (I-sim:4).

### 2.3 Equations solved every step (I-main:165-192, code units I-num:22-40, 107-110)

1. Momentum constraint $(\bar\Delta_LW)_i=8\pi s_i$ (I-main:167), $\bar A^{ij}=(\bar LW)^{ij}$.
   Code units: $W_i=V_i+\partial_iU$, $\nabla^2V_i=3\Omega_m a\,s_i$,
   $\nabla^2U=-\tfrac14\partial_jV^j$ (I-num:107-108); discrete
   $\bar A_{ij}=\partial_iV_j+\partial_jV_i-\tfrac12\delta_{ij}\partial_kV^k+2\partial_i\partial_jU$ (I-num:133).
2. Hamiltonian constraint with the reference Friedmann equation subtracted (I-main:178):
   $\bar\nabla^2\psi=-2\pi\psi^{-1}s_0-\tfrac18\psi^{-7}\bar A_{ij}\bar A^{ij}+2\pi\psi^5\hat\rho_m$.
   Code units (I-num:26):
   $(1-\tfrac{\Psi}{2a^2c^2})\nabla^2\Psi=\tfrac32a\Omega_m[s_0-(1-\tfrac{\Psi}{2a^2c^2})^6]+\tfrac14\bar A_{ij}\bar A^{ij}(1-\tfrac{\Psi}{2a^2c^2})^{-6}$.
3. CMC lapse equation (above); code units I-num:30-35 (Yukawa-type term $Q\Phi/(a^2c^2)$ with
   $Q$ of I-num:35).
4. MD shift: $\beta^i=B^i+\partial^ib$,
   $\nabla^2B^i=2\partial_j[(1+\tfrac{\Phi}{a^2c^2})(1-\tfrac{\Psi}{2a^2c^2})^{-6}\bar A^{ij}]$,
   $\nabla^2b=-\tfrac14\partial_jB^j$ (I-num:109-110).
5. Metric used by the particles (I-main:192): $ds^2=-\alpha^2dt^2+\psi^4\delta_{ij}(\beta^idt+dx^i)(\beta^jdt+dx^j)$.

Ten elliptic equations, multigrid Gauss-Seidel with AMR; source means subtracted for periodic
consistency (I-num:141, 173).

### 2.4 Code-unit variables (I-num:10-20, 53)

$\tilde x=x/L$, $d\tilde t=H_0\,dt/a^2$ (supercomoving time), $\tilde s_0=s_0/(\Omega_m\rho_c)$,
$\tilde s_i=s_i/(\Omega_m\rho_c c)$, $\tilde c=c/(LH_0)$, $\tilde\beta^i=a^2\tilde c\beta^i$,
$\tilde u^\alpha=u^\alpha/(LH_0)$, $\tilde m=m/(\Omega_m\rho_cL^3)$, and
$\alpha\equiv1+\tilde\Phi/(a^2\tilde c^2)$, $\psi\equiv a^{1/2}(1-\tilde\Psi/(2a^2\tilde c^2))$
(no linearisation implied). Remaining scalings (K̃, Ã, Ũ, Ṽ, b̃, B̃) at I-num:11-13.

### 2.5 Particles: variables, equations, sources

- Identical particles of rest mass m (I-num:67). Momentum variable: covariant spatial
  four-velocity $u_i$ (per unit rest mass; $p_i=mu_i$, I-app:23). "in the code implementation
  below we shall only use $u_i$ with a lower index, and similarly we always use $\beta^i$ with an
  upper index" (I-main:220). I-sim:6 says "in code units $\tilde m=1$" (normalisation unclear).
- Geodesic equations (I-main:209-217):
  $\frac{du_i}{dt}=-\alpha u^0\partial_i\alpha+u_j\partial_i\beta^j-\frac{u_ju_k}{2u^0}\partial_i\gamma^{jk}$,
  $u^0=\alpha^{-1}\sqrt{1+\gamma^{ij}u_iu_j}$,
  $\frac{dx^i}{dt}=\frac{\gamma^{ij}u_j}{u^0}-\beta^i$. Hamiltonian
  $H=\alpha\sqrt{m^2+\gamma^{ij}p_ip_j}-\beta^ip_i$ (I-app:21).
- Fields felt, code units (I-num:226-233): $du_i/dt=F_i$,
  $F_i=-\frac{W}{c}\partial_i\Phi+u_j\partial_i\beta^j-\frac{W^2-c^2}{Wc}\frac{1+\Phi/(a^2c^2)}{1-\Psi/(2a^2c^2)}\partial_i\Psi$,
  $\frac{dx^i}{dt}=(1+\frac{\Phi}{a^2c^2})(1-\frac{\Psi}{2a^2c^2})^{-4}\frac{c}{W}\delta^{ij}u_j-\beta^i$,
  $W^2=(\alpha u^0)^2=c^2+a^{-2}(1-\frac{\Psi}{2a^2c^2})^{-4}\delta^{ij}u_iu_j$. Newtonian limit
  $F_i\to-\partial_i\Phi$.
- Conformal sources (I-main:224-226, II:75-77): $s_0=\sqrt\gamma\rho$, $s_i=\sqrt\gamma S_i$,
  $s_{ij}=\sqrt\gamma S_{ij}$, $s=\gamma^{ij}s_{ij}$; CIC deposits (I-num:69-71)
  $s_0\propto\tilde m\tilde W/\tilde c$, $s_l\propto\tilde m\tilde u_l/\tilde c$,
  $s_{lm}\propto\tilde m\tilde u_l\tilde u_m/(\tilde W\tilde c)$ divided by cell volume. Linear
  meaning of $\delta s_0$: particle number per coordinate volume (II:290-302).
- Time stepping: KDK leapfrog, kicks split into 5 substeps (I-num:234-242, I-app:31-38). Not
  needed for Part II.

### 2.6 Linearised GRAMSES (II:116-140, 314-329, App. A)

- Background FLRW diag(-1, a²δ_ij) = the fiducial CMC background (II:116).
  $\psi=a^{1/2}(1-\Psi/2)$, $\bar\gamma_{ij}=\delta_{ij}+h_{ij}$ (II:117),
  $g_{00}=-(1+2\Phi)$, $g_{0i}=\beta_i$, $\gamma_{ij}=a^2[(1-2\Psi)\delta_{ij}+h_{ij}]$
  (II:119-121), $\Phi\equiv\alpha-1$, h_ij traceless.
- Linear MD condition (II:138): $\partial^ih'_{ij}=0$.
- Linear field equations in CMC-MD (II:475-476, cosmic time t, comoving ∂):
  $\partial^2\Psi=4\pi Ga^2\delta\rho$, $\partial^2\Phi+3\dot Ha^2\Phi=4\pi Ga^2\delta\rho+12\pi Ga^2\delta P$,
  $\delta\rho=\bar\rho\delta^C$.
- Linear momentum constraint (II:513, 517):
  $(\bar\Delta_LW)_i=\partial^2W_i+\tfrac13\partial_i\delta^{kl}\partial_kW_l=8\pi Ga^3(\bar\rho+\bar P)u^C_i$,
  $\bar A_{ij}=\partial_iW_j+\partial_jW_i-\tfrac23\delta_{ij}\partial_kW^k$.
- Linear K (II:459-462): $K=-3H(1-\Phi)+3\dot\Psi+a^{-2}\delta^{ij}\partial_i\beta_j$.
- Linear particle equations (II:316-317): $\frac{dx^i}{dt}=a^{-2}\delta^{ij}u_j-a^{-2}\delta^{ij}\beta_i$
  (index as printed), $\frac{du_i}{dt}=-\partial_i\Phi$; and (II:322)
  $u_i=a^2\delta_{ij}(u^j+\beta^j)$.

## 3. The initial-condition method of Part II

### 3.1 Input gauge

The Boltzmann code is CAMB, modified; its default variable is the synchronous-gauge density
δ^S (II:368), in Ma & Bertschinger (MB95) conventions (II:108). Synchronous metric (II:239):
$ds^2=-dt^2+a^2(\delta_{ij}+h\delta_{ij}/3+h^{\|}_{ij})dx^idx^j$,
$h^{\|}_{ij}=(\partial_i\partial_j-\delta_{ij}/3)(h+6\eta)$ (as printed; the MB95 meaning is
$(\hat k_i\hat k_j-\delta_{ij}/3)(h+6\eta)$ in Fourier space). The modified CAMB outputs the
spectrum of δ^p = δ^S − 3η (II:368) and η(z_ini) (II:374). Radiation and baryons are present in
the CAMB run (II:426).

Convention warning: II:207-274 uses MB95's conformal-time equations written with overdots and
"ȧ/a" or "H" (e.g. II:216 is MB95's 00 equation with conformal derivatives; "H" in II:222, 251,
256 is ℋ = aH). §2, §4.3, §4.4 and App. A use cosmic time t and comoving coordinates.

### 3.2 Gauge transformations (II:112-165)

Coordinate change $x^\mu\to x'^\mu=x^\mu+\xi^\mu$; unprimed = old gauge, primed = new gauge
(II:114):

- $\Phi'=\Phi+\dot\xi_0$ (II:126)
- $\beta_i'=\beta_i-\dot\xi_i-\partial_i\xi_0+2H\xi_i$ (II:127)
- $\gamma'_{ij}=\gamma_{ij}-\partial_i\xi_j-\partial_j\xi_i+2a\dot a\delta_{ij}\xi_0$ (II:128)
- $\Psi'=\Psi-H\xi_0+\tfrac13a^{-2}\delta^{ij}\partial_j\xi_i$ (II:132)
- $h'_{ij}=h_{ij}-a^{-2}(\partial_j\xi_i+\partial_i\xi_j)+\tfrac23a^{-2}\delta^{kl}\partial_k\xi_l\delta_{ij}$ (II:133)
- $\delta=\delta'+3H(1+w)\xi_0$ (II:155) [note: old = new + ...]
- $u'_i=u_i-\partial_i\xi_0$ (II:159)
- $u'^i=u^i+a^{-2}\delta^{ij}\dot\xi_j-2a^{-2}H\delta^{ij}\xi_j$ (II:163)
- $K=K'+3\dot H\xi_0+\gamma^{ij}\partial_i\partial_j\xi_0$ (II:464)

Consequences stated by the paper:
- If h_ij = 0 in the old gauge (Newtonian/Poisson without tensors), MD forces ξ_i = 0: CMC-MD and
  Newtonian share spatial coordinates at first order (II:140, 570), so
  $u^i_C=u^i_N$ (II:165, 311) while $u_i$ differs by $\partial_i\xi_0$.
- Newtonian → CMC-MD (II:565-568): $\Phi=\psi+\dot\xi_0$, $\beta_i=-\dot\xi_i-\partial_i\xi_0+2H\xi_i$,
  $\Psi=\phi-H\xi_0+\tfrac13\gamma^{ij}\partial_j\xi_i$, h_ij as in II:568, with ξ_i = 0.
- Synchronous → CMC-MD: $2a^{-2}\xi=h+6\eta$ for $\xi_i=\partial_i\xi$ (II:454);
  $\dot h=-6\dot H\xi_0-2\gamma^{ij}\partial_i\partial_j\xi_0$ (II:469).
- Synchronous ↔ Newtonian (II:251-252, conformal time):
  $\delta^N=\delta^S-\frac{3H}{2k^2}(1+w)(\dot h+6\dot\eta)$, $\theta^N=\theta^S+\frac12(\dot h+6\dot\eta)$;
  gauge invariant $\delta+\frac{3H}{k^2}(1+w)\theta$ (II:256).
- Particle coordinates: $x^i=x^i_S+a^{-2}\delta^{ij}\partial_j\xi$ (II:585).

Derived classification (from II:126-164 at linear order, w = 0) **[derived]**. Under a pure time
shift ξ_0 (slicing change): δ, Φ, K, u_i change; δ^p ≡ δ − 3Ψ, u^i and h_ij do not. Under a pure
spatial change ξ_i (threading change): δ^p, u^i, h_ij change; δ, Φ, K, u_i do not. So the
particle number contrast and the upper-index coordinate velocity depend only on the threading,
and the lower-index velocity and the energy-density contrast only on the slicing. Hence
δ^p_MD = δ^N − 3φ for any slicing with MD threading.

### 3.3 Which pair of variables is "conjugate" in each setting

Displacement method (II:178-205): $x^i(\mathbf q)=q^i+\chi^i(\mathbf q)$ (II:180), mass
conservation $\bar\rho d^3q=\bar\rho[1+\Delta]d^3x$ (II:184), Zel'dovich $\Delta=-\partial_i\chi^i$
(II:188), $v^i\equiv dx^i/dt=\dot\chi^i$ (II:192), linear continuity
$\partial_iv^i+\dot\Delta=0$ (II:196), $\partial_iv^i=-Hf_1\Delta$, $f_1\equiv d\ln D_1/d\ln a$,
$D_1(z=0)=1$ (II:200-205). A pair {Δ, v} satisfying II:196 is called conjugate.

| setting | density used | velocity used | continuity | lines |
|---|---|---|---|---|
| Newtonian N-body | δ^S | v^i_N | $\dot\delta^S+\theta^N=0$ (CDM+Λ, η̇ = 0) | II:269-273 |
| Newtonian gauge proper | δ^N | v^i_N | $\dot\delta^N+\theta^N-3\dot\phi=0$ (not conjugate) | II:232 |
| CMC-MD energy density | δ^C | u^i_C | $\dot\delta^C+\partial_iu^i_C-3\dot\Psi=0$ (not conjugate) | II:288 |
| GRAMSES particles | δ^p ≡ δ^C − 3Ψ = δs_0/s_0 | u^i_C = u^i_N | $\dot\delta^p+\partial_iu^i_C=0$ | II:292-300 |
| N-body gauge (Fidler+2015, not in Part II) | δ^S (coordinate = comoving density) | v_N | standard | external, II:278 |

Key identity (II:308): $\delta^p=\delta^S-3\eta$ (linear, any epoch). η̇ = 0 when only CDM and Λ
(θ^S_tot = 0 in II:243), so δ^p and δ^S differ by a time-independent field (II:310-311).
Default 2LPTic uses $f_1=\Omega_m(a)^{0.6}$, $\Omega_m(a)=\Omega_{m,0}a^{-3}/(H/H_0)^2$ (II:276).

### 3.4 Positions

First-order Zel'dovich displacement only; the 2LPT term of 2LPTic is turned off, also in the
default runs used for comparison (II:368). Input spectrum: $P_{\delta^p}(k;z_{ini})$ for GRAMSES
(CMC) ICs, $P_{\delta^S}(k;z_{ini})$ for Newtonian ICs, taken directly at z_ini from (modified)
CAMB, no back-scaling (II:368 footnote, II:419). Pre-initial load: "regular grid or glass"
(II:178); which one is not stated (N_p = 1024³ suggests a grid).

### 3.5 Velocities: finite difference (II:339-345)

Realise $\chi^i(z_{ini})$ and $\chi^i(z_\pm)$, $z_\pm=z_{ini}\pm\Delta z$, $\Delta z\ll z_{ini}$,
from $P_\Delta(k;z_{ini})$ and $P_\Delta(k;z_\pm)$ with the same random number sequence and seeds
(II:343). With $\Delta x^i\equiv x^i(z_-)-x^i(z_+)$ (II:339):

$$v^i\approx\frac{\Delta x^i}{\Delta t}=\frac{H}{a}\frac{\chi^i(z_-)-\chi^i(z_+)}{2\Delta z}\qquad\text{(II:341)}$$

The output is the contravariant coordinate velocity $u^i$ (II:329). Positions are the z_ini
realisation.

Alternative two-step method (II:333-334): positions from $P_{\delta^p}$, velocities by the
standard method with $P_{\delta^S}$ and the (scale-independent) f_1, using $u^i_C=u^i_N$; the
velocity-divergence spectra of the two methods differ by "well below 0.1%". Equivalently
**[derived]**: $u^i=Hf\chi^i_S$ with $\chi_S$ the Zel'dovich displacement of δ^S, while particles
sit at $q+\chi_p$; $\chi_p-\chi_S=3\nabla\nabla^{-2}\eta$ (Fourier
$-3i\mathbf k\eta_{\mathbf k}/k^2$) carries no velocity.

### 3.6 Radiation fix and normalisation (II:345, 370-390)

Neighbouring spectra with radiation removed and η frozen (II:372):

$$\delta^p(k;z_\pm)=\frac{D_1(z_\pm)}{D_1(z_{ini})}\delta^S(k;z_{ini})-3\eta(k;z_{ini})$$

D_1 = synchronous-gauge linear growth factor "in the absence of radiation" (II:374); η(z_ini)
output by CAMB. For the synchronous/Newtonian case the analogue is
$P^S(k;z_\pm)=[D_1(z_\pm)/D_1(z_{ini})]^2P^S(k;z_{ini})$ **[inferred]** (II:378 states it for σ8).

2LPTic renormalises every input spectrum to a σ8 that must be supplied (II:376 footnote), so the
z± spectra need σ8 values consistent with the above:

- $\sigma^S_8(z_\pm)=\frac{D_1(z_\pm)}{D_1(z_{ini})}\sigma^S_8(z_{ini})$ (II:378)
- $\sigma^p_8(z_\pm)=\sqrt{\left[\frac{D_1(z_\pm)}{D_1(z_{ini})}\sigma^S_8(z_{ini})\right]^2+9[\sigma^\eta_8(z_{ini})]^2-6\frac{D_1(z_\pm)}{D_1(z_{ini})}[\sigma^{S\eta}_8(z_{ini})]^2}$ (II:384)
- $[\sigma^{S\eta}_8(z_{ini})]^2=\frac{[\sigma^S_8(z_{ini})]^2-[\sigma^p_8(z_{ini})]^2+9[\sigma^\eta_8(z_{ini})]^2}{6}$ (II:388)

σ^η_8: normalisation of $P_{\eta\eta}$; σ^{Sη}_8: of the δ^S-η cross spectrum (II:386).
"Not corrected" (Fig. 4) means passing CAMB's own σ8(z±) instead.

Back-scaling, standard 2LPTic: realise the z = 0 CAMB spectrum scaled back with the ΛCDM D_1
(II:360, 424); not used by the paper except as a Fig. 4 comparison.

### 3.7 From u^i to the particle variable u_i (done inside GRAMSES, once)

GRAMSES reads u^i, solves the linearised momentum constraint for the shift once at z_ini
(II:326, code units, verbatim):

$$(\bar\Delta_L\beta_{\rm ini})^i-6\Omega_m\beta^i_{\rm ini}=6\frac{\Omega_m}{a}u^i_{\rm ini}$$

then sets $u_i=a^2\delta_{ij}(u^j+\beta^j)$ (II:322, 329) and starts. Physical-unit content
**[derived]**, from the MD equation plus II:513: with
$m^2\equiv-3a^2\dot H=12\pi Ga^2\bar\rho_m=\tfrac92\Omega_m(a)\mathcal H^2$,
$(\Delta_L\beta)^i=16\pi G\bar\rho\,a^2(u^i+\beta^i)$, i.e. for the longitudinal part
$\beta^i_\parallel(\mathbf k)=-\frac{m^2}{k^2+m^2}u^i_\parallel(\mathbf k)$, hence
$a^{-2}\partial_iu_i^C=\theta^N\,k^2/(k^2+m^2)$. This reproduces the Fig. 3 linear CMC/N velocity
ratio to 3% (§5.3). The code-unit coefficients in II:326 (no a or c̃ on the β term) could not be
reconciled with the unit table I-num:10-13; use the physical form.

### 3.8 Metric initial data

None. In the fully constrained scheme the metric is entirely determined by the particles (II:46,
II:171); the first GRAMSES step solves all ten elliptic equations. The only extra step is §3.7.

### 3.9 Radiation, baryons, Λ

- Radiation and baryons: in the CAMB linear solution only; δ^S(z_ini) and η(z_ini) carry their
  history. The particle evolution has neither (II:345, 374, 438). Removed from the velocity by
  §3.6. The paper plans to treat radiation as linear perturbations later (II:363).
- Λ: in the reference Friedmann equations (ρ_Λ in the lapse equation) and in D_1.
- One particle species (dark matter) (II:399). Whether δ^S is CDM-only or CDM+baryon is not
  stated; II:267 says "the density contrast of dark matter only" in the derivation.

### 3.10 Transfer functions, z_ini, normalisation, seeds

- Transfer functions: modified CAMB (version, accuracy settings and cosmology not given in II).
- z_ini = 99 and 49 for the tests (II:395, 406); Part I runs used z_ini = 49 (I-sim:3).
  Typical range 49 ≲ z_ini ≲ 99 (II:174).
- Normalisation: σ8 (top hat of 8 h⁻¹Mpc, II:376 footnote) at z_ini and z±; numerical value not
  stated. **[inferred]**: the linear synchronous spectrum of Fig. 2 at z = 49 integrates to
  σ8(z=49) = 0.0213; times the ΛCDM D_1(0)/D_1(49) = 39.16 for Part I's cosmology this gives
  σ8(0) ≈ 0.83. The k → 0 plateau of the CMC spectrum, $P_{\delta^p}\to9P_\eta\approx4.67\times10^5$
  (h⁻¹Mpc)³ at k = 10⁻⁴ (fig), equals 9P_R for A_s ≈ 2.1e-9 if n_s ≈ 0.965.
- Seeds: one seed for all realisations (II:368), value not given. The same seed for S and CMC
  ICs, so ratios of spectra are free of realisation scatter (II:401).

### 3.11 Recipe in order

1. Linear Boltzmann run (synchronous gauge) to z_ini: δ^S(k), η(k), and θ^N for checks.
2. $P_{\delta^p}(k;z_{ini})=|\delta^S-3\eta|^2$; neighbouring $P_{\delta^p}(k;z_\pm)$ from II:372;
   σ8 values from II:378, 384, 388.
3. Gaussian field with fixed seed; Zel'dovich displacements χ(z_ini), χ(z±) (2LPT off).
4. Positions $q+\chi(z_{ini})$; velocities $u^i$ from II:341 (or $Hf\chi_S$, §3.5).
5. In the evolution code: shift from II:326 (MD), $u_i=a^2(u^i+\beta^i)$, then start.

## 5. Linear-theory relations for the comparison curves

### 5.1 Conventions

- $\langle\delta_{\mathbf k}\delta^*_{\mathbf k'}\rangle=(2\pi)^3\delta_D(\mathbf k-\mathbf k')P(k)$,
  $\Delta^2(k)=k^3P/(2\pi^2)$ (I-sim:182).
  $\sigma_8^2=\int d\ln k\,\Delta^2(k)W^2(kR)$, $R=8\,h^{-1}$Mpc,
  $W(y)=3(\sin y-y\cos y)/y^3$ (standard; II:376 defines it in words).
- θ: Part II's plotted θ = ∂_i of the IC velocity (u^i, or lower u_i for GRAMSES). MB95's θ is
  conformal: $\theta_{MB}=a\,\partial_i(dx^i/dt)$.

### 5.2 Exact relations (use with Boltzmann output, radiation included)

- $\delta^p=\delta^S-3\eta$ (II:308). Hence $P_{pp}=P_{SS}+9P_{\eta\eta}-6P_{S\eta}$ (sign of η
  as in MB95/CAMB).
- $\delta^N=\delta^S-3\mathcal H(1+w)\alpha$, $\theta^N=\theta^S+k^2\alpha$,
  $\alpha=(h'+6\eta')/(2k^2)$ (conformal; II:251-252 written with overdots; the sign of the δ
  relation was checked on the MD superhorizon limit $\delta^N\to-2\phi$ **[derived]**).
- $u^i_C=u^i_N$; for CDM $\theta^S_c=0$, so $\theta^N=k^2\alpha=-\delta^{S\prime}_c$.
- Synchronous variables: CAMB evolves `etak` = kη; CLASS outputs η, h′ in synchronous gauge
  (check the names for your version).

### 5.3 Closed forms, CDM + Λ, no radiation [derived]

Notation: $x=(k/\mathcal H)^2$, $f=d\ln D_1/d\ln a$, $\Omega_m(a)$,
$m^2\equiv-3a^2\dot H=12\pi Ga^2\bar\rho_m=\tfrac92\Omega_m(a)\mathcal H^2$ (the Yukawa mass of
II:476). Then η̇ = 0, φ = ψ, φ̇ = H(f−1)φ, and:

- $\phi=-\tfrac32\Omega_m(a)\delta^S/x$; $\eta=-(f+\tfrac32\Omega_m)\delta^S/x$ (constant)
- $\delta^N=\delta^S(1+3f/x)$
- $\delta^p=\delta^N-3\phi=\delta^S\left[1+(3f+\tfrac92\Omega_m)/x\right]$
- $P_{pp}/P_{SS}=\left[1+(3f+\tfrac92\Omega_m)\mathcal H^2/k^2\right]^2$; MD: $(1+7.5\mathcal H^2/k^2)^2$
- $f_p\equiv d\ln\delta^p/d\ln a=f\big/\left[1+(3f+\tfrac92\Omega_m)/x\right]$
- Newtonian → CMC time shift: $\xi_0=-3a^2(H\psi+\dot\phi)/(k^2+m^2)=-3a^2Hf\phi/(k^2+m^2)$
- $\beta^i_\parallel=-\frac{m^2}{k^2+m^2}u^i_\parallel$
- $\theta_C^{\rm lower}\equiv a^{-2}\partial_iu^C_i=\theta^N_{\rm coord}\frac{k^2}{k^2+m^2}$, with
  $\theta^N_{\rm coord}=\partial_iu^i=-Hf\delta^S$; so
  $P^{C,\rm lower}_{\theta\theta}/P^N_{\theta\theta}=[k^2/(k^2+m^2)]^2$
- $\Psi_C=-4\pi Ga^2\bar\rho\,\delta^p/(k^2+m^2)=\phi\,(x+3f+\tfrac92\Omega_m)/(x+\tfrac92\Omega_m)$
- $\delta^C=\delta^p+3\Psi_C=\delta^p\,k^2/(k^2+m^2)$;
  $\Phi_C=-4\pi Ga^2\bar\rho\,\delta^C/(k^2+m^2)$ (II:476 with δP = 0)

Checks against the figures: f_p (Fig. 1) matches to ±0.001 at the two points checked. The
P^CMC_θθ/P^N_θθ ratio is 0.0593 vs 0.0611 (z=99) and 0.153 vs 0.155 (z=49) at k = 0.002225
(Fig. 3 linear curves). P_pp/P_SS at k = 0.002225 is 38.2 (z=99) and 12.9 (z=49), against
41.4 and 13.3 on the Boltzmann curves of Fig. 2: radiation changes these by 8% and 3%, so the
comparison curves must come from §5.2. Including radiation in H alone gives 40.1 at z = 99.

### 5.4 Plotted velocity units [inferred]

$\theta=\nabla\cdot(a^{1/2}\dot{\mathbf x})$ with $\dot{\mathbf x}$ in km/s per comoving h⁻¹Mpc
units, so $P^N_{\theta\theta}=aH^2f^2P_{SS}$ (sub-horizon, no radiation), H = 100E(z)
km s⁻¹(h⁻¹Mpc)⁻¹; approximately independent of z in matter domination, as in Fig. 3.

### 5.5 Finite-difference truncation [derived]

For D ∝ a: $\frac{D(z-\Delta z)-D(z+\Delta z)}{2\Delta z}=\frac{1}{(1+z)^2-\Delta z^2}$, so
$P^{FD}_{\theta\theta}/P_{\theta\theta}=1+2(\Delta z)^2/(1+z)^2+O(\Delta z^4)$; this matches the
Fig. 3 subpanels exactly. A 4-point stencil removes it.

### 5.6 σ8 and growth

II:378, 384, 388 (§3.6). D_1: ΛCDM, no radiation, D_1(0) = 1 (II:200, 374); for Part I's
cosmology D_1(z=0)/D_1(z=49) = 39.16 **[derived]**.

### 7b. Specific to the constrained (elliptic) formulation, with suggested equivalents

1. **Gauge: CMC slicing + MD shift, both elliptic.** A Z4c code with Bona-Massó lapse and a
   Gamma-driver shift is not in this gauge, and every Part II comparison curve is CMC-MD
   specific for k ≲ few ℋ. Equivalents:
   - Part II itself has no evolution. Build CMC-MD data exactly at z_ini (7b.2) and measure the
     IC spectra; then all four figures can be compared one-to-one.
   - Slicing closest to CMC: Bona-Massó with a reference curvature,
     $\partial_t\alpha=\beta^k\partial_k\alpha-\alpha^2f(\alpha)(K-K_{\rm ref}(t))$,
     $K_{\rm ref}=-3H(t)$ of the same reference FLRW. Without K_ref the background lapse drifts;
     harmonic slicing gives α ∝ a³. Linearised, the time offset from CMC obeys
     $\ddot\xi_0+f(1)(k^2+m^2)a^{-2}\xi_0=\dot\Phi_C$ **[derived]** (f(1) = 2 for 1+log): a
     driven oscillator with $\omega\ge\sqrt{f\cdot4.5\,\Omega_m}\,H$. It tracks CMC up to
     O(H²/ω²) and gauge oscillations; start with α = α_CMC and K = −3H to avoid exciting them.
   - Threading closest to MD: at linear order MD ⇔ ∂_tΓ̃^i = 0 with Γ̃^i = ∂_jh_ij. A Gamma-driver
     started with Γ̃^i = 0 and β = β_MD approximates it only where shift waves equilibrate.
   - Gauge-robust comparison **[derived]**: δ^p and u^i depend only on the threading, u_i and δ
     only on the slicing (§3.2). From the code's $h_{ij}=\tilde\gamma_{ij}-\delta_{ij}$
     (traceless at linear order) and K, map to CMC-MD in Fourier space:
     $\delta^p_{MD}=\delta^p_{\rm code}-\tfrac34\hat k^i\hat k^jh_{ij}$,
     $\theta^u_{MD}=\theta^u_{\rm code}+\tfrac34\partial_t(\hat k^i\hat k^jh_{ij})$,
     $\xi_0=-a^2\delta K_{\rm code}/(k^2+m^2)$, $\delta^C=\delta_{\rm code}-3H\xi_0$,
     $a^{-2}\partial_iu_i^C=a^{-2}\partial_iu_i^{\rm code}+a^{-2}k^2\xi_0$.
     Check: synchronous → MD gives δ^S − 3η and θ^N, as in II:308 and II:252.
     Alternatively compare gauge-invariant variables (Bardeen φ, comoving density δ^S).
2. **Initial metric data.** GRAMSES needs particles only (II:171); Z4c needs (χ, γ̃_ij, K̂,
   Ã_ij, Γ̃^i, Θ, α, β^i) satisfying the Hamiltonian and momentum constraints. CMC-MD data at
   z_ini, by FFT inside the IC generator (one-time solves, none during evolution):
   $\tilde\gamma_{ij}=\delta_{ij}$, Γ̃^i = 0, Θ = 0, $\chi=\psi^{-4}$ with
   $\psi=a^{1/2}(1-\Psi/2)$, $(k^2+m^2)\Psi=-4\pi Ga^2\bar\rho\,\delta_n$ (δ_n the deposited
   number contrast of the actual particles; exact to O(Ψ², v²)), K = −3H,
   $\tilde A_{ij}=\psi^{-6}\bar A_{ij}$ with $\bar A=\bar LW$ from II:513, α from II:476, β from
   §3.7, and particle $u_i=a^2(u^i+\beta^i)$. Our particle variable u_i is the same as GRAMSES's.
   The η-frozen synchronous metric would also do, but then the ICs are not in the Part II gauge.
3. **No tensor modes / conformal flatness.** Z4c carries tensor modes; with γ̃ = δ initially they
   appear only at second order. Nothing to do at IC level.
4. **Lapse equation with Yukawa screening** (I-main:198): no counterpart; in our code α evolves.
   The same mass m² sets the CMC-MD comparison curves (§5.3).
5. **Radiation.** Part II removes radiation from velocities by freezing η and using a ΛCDM D_1. A
   radiation-free evolution needs the same treatment (or back-scaling); otherwise expect the
   Fig. 4 offsets (−1.9% in P_θθ at z = 49, more at z = 99).
6. **Finite-difference velocities.** Gauge-agnostic and portable, valid for any conjugate pair
   {δ^p_X, u^i_X} of a threading X. In double precision with Δz/z ~ 1% the only error is
   2Δz²/(1+z)².
