# Test-particle cluster in a fixed black hole spacetime

Validation of the particle module with clusters of 10^2, 10^3 and 10^4 massive test
particles in a fixed Schwarzschild (a = 0) or Kerr (a = 0.9 M) black hole spacetime,
with the analytic Cartesian Kerr-Schild metric and with the same metric stored on a
statically refined mesh (cubic Hermite reconstruction), stress-energy deposited on the
mesh without back-reaction. All runs: GPU (A100), 2026-11-13. Everything below is
measured; nothing was tuned after the fact.
