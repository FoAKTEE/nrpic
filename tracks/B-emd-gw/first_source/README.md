# first_source (helper package of B-emd-gw, wave 2)

The first gravitational-wave source in full relativity: crossed waves (1, eps, 0) at
delta = 0.01 on 64^3 cells, eps = 0, 0.1, 0.3, 1, and a second-gauge run; analysis with
`../gw_diag`. Work in progress; predictions in `JOURNAL.md`.

| Path | What |
|---|---|
| `inputs/crossed.athinput` | AthenaK input of the scan |
| `scripts/build_ic.sh` | initial data of the four eps values with `cosmo/ic/make_east.py` |
| `JOURNAL.md` | predictions (written before the runs) and outcomes |
